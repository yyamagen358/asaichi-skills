# 健康記録をグラフ化

血圧、体重、血糖値などの健康データを折れ線グラフや表に変換します。手帳に書いた記録や口頭での数値から、見やすいグラフを作成します。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「血圧」「体重」「健康記録」「グラフ」と言った場合
- 「数値をグラフにして」「見える化したい」と言った場合
- 「健康手帳の写真」「メモした数値」を提供された場合
- 「お医者さんに見せたい」「記録を整理したい」と言った場合

## 手順

### ステップ1：健康データを受け取る

ユーザーからデータを受け取ります。データが無い場合は、やさしく以下のように案内します：

```
健康データをお聞かせください。以下のどの方法でもOKです：

1. 手帳やメモの写真を送る
2. 数値をそのまま話す（例：「1月10日 血圧130/85、体重65kg」）
3. Excelやテキストファイルを送る

どんな形式でも大丈夫ですよ。
```

対応するデータの種類：
- 血圧（上/下）
- 体重
- 血糖値
- 体温
- 歩数
- その他の数値データ

### ステップ2：データを整理・構造化する

受け取ったデータを日付順に整理します：

- 手帳の写真の場合：画像を読み取りデータを抽出
- テキストの場合：数値と日付を解析
- 欠損値がある場合はユーザーに確認
- 明らかに異常な値（入力ミスの可能性）は確認する

データをテーブル形式に整理して、ユーザーに「この内容で合っていますか？」と確認します。

### ステップ3：グラフを生成する

`matplotlib` ライブラリを使ってグラフを生成します。

```bash
pip install matplotlib japanize-matplotlib openpyxl
```

Pythonスクリプトで以下を生成：

- **折れ線グラフ**：日付を横軸、数値を縦軸
  - 血圧の場合：上と下を別の線で表示、正常範囲を色付き帯で表示
  - 体重の場合：目標値があれば点線で表示
- **グラフの設定**：
  - 日本語フォント対応（`japanize-matplotlib`）
  - 見やすいフォントサイズ（高齢者向けに大きめ）
  - 日付のラベルは斜めに配置
  - グリッド線を表示
- 画像ファイル（PNG）として保存

### ステップ4：Excel版も出力する（オプション）

データをExcelファイルとしても保存します：
- 日付と数値の一覧表
- Excel内にグラフを埋め込み
- 次回の記録を追加しやすいフォーマットにする

### ステップ5：完成を報告し、追加対応を提案する

ファイルの保存場所を伝えた後、以下を提案します：

- 「次回のデータを追加する時はまた言ってくださいね」
- 「お医者さんに見せる用にPDFにもできますよ」
- 「先月との比較グラフも作りましょうか？」

## 重要な注意点

- 健康データは個人情報のため、慎重に扱う
- 医療的なアドバイスは絶対にしない（「数値が高いので病院へ」等は言わない）
- グラフは印刷してもきれいに見えるよう、十分な解像度（300dpi以上）で出力
- 高齢者が見やすいよう、文字サイズ・線の太さ・色のコントラストに配慮する
- `matplotlib` がインストールされていない場合は自動でインストールする
