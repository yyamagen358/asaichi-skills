# マニュアル自動生成

5つの質問に答えるだけで、業務引継ぎ用の手順書を自動生成します。属人化した業務を誰でもできるようにドキュメント化します。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「マニュアル生成」「引継ぎ」「手順書を自動」と言った場合
- 「業務を引き継ぎたい」「誰でもできるようにしたい」と言った場合
- 「属人化を防ぎたい」「マニュアル化したい」と言った場合
- 退職・異動前に業務を整理したいという意図がある場合

## 手順

### ステップ1：5つの質問で情報を収集する

以下の5つの質問を、1つずつ丁寧に聞いていきます：

```
マニュアルを作るために、5つだけ質問させてください。
ざっくりとした回答で大丈夫ですよ。

【質問1/5】誰がやる業務ですか？
（例：「経理担当者」「新人スタッフ」「パートさん」）

【質問2/5】何をする業務ですか？
（例：「毎月の請求書発行」「在庫の棚卸し」「お客様への電話対応」）

【質問3/5】具体的な手順を教えてください。覚えている範囲でOKです。
（例：「まずExcelを開いて、次に〇〇シートを選んで…」）

【質問4/5】注意点やコツはありますか？
（例：「〇〇の場合は上司に確認が必要」「月末は特に急ぐ」）

【質問5/5】使うツールやシステムはありますか？
（例：「Excel」「社内システム」「電話」「FAX」）
```

一度に全部聞かず、1問ずつ会話形式で進めます。ユーザーの回答が短い場合は、やさしく深掘りします。

### ステップ2：回答内容を整理・構造化する

5つの回答をもとに、以下の構造でマニュアルを設計します：

1. **業務名・概要**：質問2の回答をもとに
2. **担当者・対象者**：質問1の回答をもとに
3. **必要なツール・前提条件**：質問5の回答をもとに
4. **手順（番号付き）**：質問3の回答を詳細なステップに分解
   - 各ステップに「やること」「確認ポイント」を記載
   - スクリーンショットの挿入箇所を示す（[画像: 〇〇の画面] の形式で）
5. **注意点・トラブル対応**：質問4の回答をもとに
6. **よくある質問（FAQ）**：想定される疑問を3〜5個生成

### ステップ3：確認を取る

構造化した内容をユーザーに見せて確認します：

```
以下の内容でマニュアルを作成します。確認をお願いします：

■ 業務名：〇〇
■ 対象者：〇〇
■ 手順数：〇ステップ
■ 使用ツール：〇〇

手順の概要：
1. 〇〇する
2. 〇〇する
3. ...

修正や追加があれば教えてください。OKなら「OK」と言ってください。
```

### ステップ4：マニュアル文書を生成する

確認が取れたら、以下の形式でマニュアルを出力します：

**Markdown形式**（デフォルト）：
- 見出し・番号付きリスト・表を使った読みやすい形式
- そのまま社内Wikiや共有ドキュメントにコピー可能

**Word形式**（.docx）（希望があれば）：
- `python-docx` を使って生成
- 表紙、目次、ページ番号付き
- 印刷してファイリングできるレイアウト

ファイル名の例：「請求書発行マニュアル.md」「請求書発行マニュアル.docx」

### ステップ5：追加対応を提案する

```
マニュアルが完成しました！

さらにこんなこともできます：
- 「チェックリスト版も作りましょうか？」（毎回の作業確認用）
- 「Word版も作りましょうか？」（印刷用）
- 「別の業務のマニュアルも作りますか？」
```

## 重要な注意点

- 質問は一度に全部出さず、1つずつ会話形式で進める（ユーザーの負担を減らす）
- ユーザーの回答が曖昧でも否定せず、「こういうことですか？」と確認する
- 専門用語はできるだけ平易な言葉に置き換える
- 手順の抜け漏れが疑われる場合は「この間に何かありますか？」と確認する
- 機密情報が含まれる可能性があるため、内容に関する余計なコメントはしない
- 生成後の修正にも柔軟に対応する（「ステップ3を分割して」など）
