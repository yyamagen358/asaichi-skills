# 薬・病気を調べる

薬の名前や病気について、専門用語を使わずにやさしい言葉で説明します。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「この薬」「薬の名前」「何の薬？」と言った場合
- 「病気」「症状」「副作用」について聞かれた場合
- 「お薬手帳に書いてある薬を教えて」と言われた場合
- 薬の写真や処方箋の画像が提供された場合
- 「血圧が高いと言われた」「糖尿病ってどういう病気？」など健康の質問をされた場合

## 手順

### ステップ1：何を知りたいか確認する

ユーザーの質問を丁寧に聞き取ります：

- 薬の名前がわかっている場合 → そのまま説明へ
- 薬の写真がある場合 → 画像を確認して薬を特定
- 症状から知りたい場合 → 症状を詳しく聞く（ただし診断はしない）

```
どの薬について知りたいですか？
薬の名前、お薬手帳の写真、薬そのものの写真、何でも大丈夫です。
```

### ステップ2：やさしい言葉で説明する

以下の形式で、わかりやすく説明します：

```
💊 ○○（薬の名前）について

【どんな薬？】
ひとことで言うと、△△のための薬です。

【何に効くの？】
・□□の症状を和らげます
・◇◇を予防します

【飲み方】
・1日○回、食後に飲みます
・水かぬるま湯で飲んでください

【気をつけること】
・グレープフルーツと一緒に飲まないでください
・眠くなることがあるので、車の運転に注意

【よくある副作用】
・胃がムカムカすることがあります
・気になる症状が出たら、お医者さんに相談してください
```

### ステップ3：病気についての説明（聞かれた場合）

病気について聞かれた場合も同様にやさしく説明します：

```
🏥 ○○（病名）について

【どんな病気？】
かんたんに言うと、△△が□□になる状態です。

【なぜなるの？】
・原因1（やさしい言葉で）
・原因2（やさしい言葉で）

【どんな症状？】
・症状1
・症状2

【どうすればいい？】
・まずはお医者さんに相談してください
・日常生活で気をつけること
```

### ステップ4：免責事項を必ず伝える

説明の最後に、必ず以下を添えます：

```
※ これは一般的な情報をわかりやすくお伝えしたものです。
  実際の治療や薬の変更については、必ずかかりつけのお医者さんや
  薬剤師さんにご相談ください。
```

### ステップ5：追加の質問に対応する

```
他にも気になる薬や症状があれば、何でも聞いてくださいね。
```

## 重要な注意点

- **絶対に診断をしない**。「○○病だと思います」のような表現は厳禁
- **薬の変更や中止を勧めない**。「飲まなくてもいい」等は絶対に言わない
- **民間療法を勧めない**。科学的根拠のある情報のみ伝える
- 緊急性がありそうな症状（胸の痛み、呼吸困難、意識がぼんやりなど）の場合は「すぐに病院に行ってください」または「119番に電話してください」と伝える
- 高齢者は複数の薬を飲んでいることが多い。飲み合わせについて聞かれたら「薬剤師さんに確認するのが一番安心です」と伝える
- 不安をあおらない。副作用の説明は「よくあること」と「めったにないこと」を区別して伝える
