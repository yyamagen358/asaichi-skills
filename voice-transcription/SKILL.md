# 声で文字おこし

音声ファイル（mp3、wav、m4aなど）を受け取り、その内容を文字に書き起こします。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「文字おこし」「文字起こし」と言った場合
- 「音声を文字に」「この音声を」「録音を文字に」と言った場合
- 音声ファイル（mp3、wav、m4a、ogg、webm）が提供された場合
- 「聞き取れなかった」「もう一度聞きたい」など、音声の内容確認を求めた場合

## 手順

### ステップ1：音声ファイルを確認する

ユーザーが音声ファイルを提供しているか確認します。ファイルが無い場合は、やさしく以下のように案内します：

```
音声ファイルをドラッグ＆ドロップするか、ファイルのパスを教えてください。
mp3、wav、m4aなどの形式に対応しています。
```

### ステップ2：ファイルを読み取る

提供された音声ファイルをReadツールで読み取ります。対応形式を確認し、読み取れない場合はその旨を伝えます。

### ステップ3：文字起こしを実行する

Claudeの組み込み機能を使って音声内容を文字に起こします。外部APIが利用可能な場合（Whisper APIなど）はそちらも活用します。

### ステップ4：結果を整えて返す

書き起こした文字を、読みやすい形に整えて返します：

- 句読点を適切に入れる
- 段落を分ける（話題が変わるところで）
- 聞き取りにくい箇所は「（聞き取り不明）」と表記する
- 話者が複数いる場合は「話者A：」「話者B：」のように分ける

### ステップ5：追加の対応を提案する

文字起こし結果を渡した後、以下を提案します：

- 「要約もお作りしましょうか？」
- 「テキストファイルとして保存しましょうか？」

## 重要な注意点

- 音声の品質が悪い場合は、正直に「聞き取りにくい部分がありました」と伝える
- 個人情報が含まれる可能性があるため、内容について余計なコメントはしない
- ユーザーは高齢者が多いため、操作手順はゆっくり、丁寧に説明する
- 長い音声の場合は、途中経過を伝える（「只今書き起こし中です…」など）
