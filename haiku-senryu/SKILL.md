# 俳句・川柳を作る

テーマや気分を伝えるだけで、俳句・川柳を作成します。季語の提案や添削にも対応。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「俳句」「川柳」「五七五」と言った場合
- 「一句詠んで」「句を作って」と頼まれた場合
- 「季語を教えて」「添削して」と言われた場合
- 「今日の気分を句にして」など詩的な表現を求められた場合
- 自作の俳句・川柳を見せて感想を求められた場合

## 手順

### ステップ1：テーマと種類を確認する

俳句と川柳の違いを踏まえて確認します：

- **俳句**：季語あり、自然や情景を詠む、文語調も可
- **川柳**：季語なし、人間や世相を詠む、口語調でユーモア

```
どんなテーマで詠みましょうか？
季節の風景なら俳句、日常のおかしみなら川柳がぴったりです。
```

テーマが漠然としている場合は、今の季節や天気から提案します。

### ステップ2：句を生成する

3〜5句を提案します。バリエーションを持たせます：

```
「春の散歩」をテーマに詠んでみました：

一、 花びらの 絨毯踏みて 犬も笑む
二、 春風に 帽子押さえて 坂の上
三、 たんぽぽの 綿毛ふわりと 子の手から

お気に入りはありますか？もっと作ることもできますよ。
```

### ステップ3：季語の解説を添える（俳句の場合）

俳句を作った場合は、季語について簡単に解説します：

```
【季語メモ】
・「花びら」→ 春の季語。桜を指すことが多いです
・「たんぽぽ」→ 春の季語。身近な春の象徴ですね
```

### ステップ4：添削を求められた場合

ユーザーが自作の句を見せてくれた場合は、以下の観点で丁寧に添削します：

1. **音数**：五七五になっているか（字余り・字足らずも味になる場合あり）
2. **季語**：適切な季語が入っているか（俳句の場合）
3. **切れ字**：「や」「かな」「けり」の使い方
4. **情景**：映像が浮かぶか、具体的か
5. **良いところを先に褒める**：必ず良い点を見つけてから改善案を出す

```
素敵な句ですね！「○○」という表現がとても良いです。
もし一箇所だけ手を入れるなら、「△△」を「□□」にすると
もっと情景が浮かぶかもしれません。いかがでしょう？
```

### ステップ5：発展的な楽しみ方を提案

```
・連作（同じテーマで5句）にまとめてみませんか？
・短冊に書いて飾るのも素敵ですね
・句会（お友達と見せ合い）もおすすめです
```

## 重要な注意点

- 俳句・川柳は「正解」がない芸術。ユーザーの感性を否定しない
- 添削は提案であって押しつけではない。「こうすべき」ではなく「こうしても面白いかも」
- 高齢者にとって俳句は大切な趣味。敬意を持って対応する
- 季語の知識は正確に。間違った季語を教えない
- 盗作にならないよう、有名な句と似すぎないように注意する
- ユーモアのある川柳でも、人を傷つける内容は避ける
