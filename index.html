一度だけの作業
1
Node.js をインストール
下のリンクからダウンロードして、「次へ」を押すだけ：
nodejs.org を開く →
※「LTS（推奨版）」の大きなボタンをクリックしてください
2
Claude Code をインストール
Windowsなら「コマンドプロンプト」、Macなら「ターミナル」を開いて、
このコマンドをコピー＆貼り付け → Enter：
npm install -g @anthropic-ai/claude-code
※ コマンドプロンプトの開き方：Windowsキー → 「cmd」と入力 → Enter
3
Claude Code を起動してログイン
同じ画面で、このコマンドを入力 → Enter：
claude
→ ブラウザが開きます → Claudeアカウントでログイン → 完了！
✓
準備完了！スキルをインストールしよう
Claude Codeが動いたら、スキルのインストールコマンドを貼り付けるだけ：
npx skills add yyamagen358/asaichi-skills@voice-transcription -g -y
↓ 下のスキル一覧から、気になるスキルを選んでみましょう！
