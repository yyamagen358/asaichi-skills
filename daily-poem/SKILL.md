# 毎日自動で詩を投稿

毎日の季節や日付に合わせた詩・ポエムを自動生成し、SNSへの投稿用テキストを作成します。Cronトリガーとの連携で完全自動化が可能です。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「詩を投稿」「自動投稿」「毎日ポエム」と言った場合
- 「SNSに詩を」「毎日更新したい」と言った場合
- 「ポエムを書いて」「今日の詩」と言った場合
- Cronトリガーから自動実行された場合

## 手順

### ステップ1：詩のテーマを決定する

手動実行の場合はユーザーに確認します：

```
どんな詩を作りましょうか？

1. 今日の日付・季節に合わせた詩（おまかせ）
2. テーマを指定（例：「桜」「感謝」「朝の光」）
3. 気分に合わせて（例：「元気が出る詩」「しみじみする詩」）

どれでもOKです。おまかせなら「1」でどうぞ。
```

自動実行（Cron）の場合は以下の情報から自動でテーマを決定：
- 今日の日付・曜日
- 季節（二十四節気を参考に）
- 記念日・行事（あれば）
- 天候（API連携があれば）

### ステップ2：詩を生成する

以下のルールで詩を生成します：

- **文字数**：100〜200文字程度（SNS投稿に最適な長さ）
- **スタイル**：
  - やさしい日本語で
  - 五感に訴える表現を入れる
  - 読後に温かい気持ちになる内容
  - 難しい漢字は避ける
- **フォーマット**：
  - 改行を適切に入れて読みやすく
  - タイトルを付ける

### ステップ3：SNS投稿用にフォーマットする

各SNS向けに最適化したテキストを生成します：

- **共通**：
  - ハッシュタグを3〜5個追加（例：#今日の詩 #ポエム #朝の言葉）
  - 絵文字を適度に使用
- **Twitter/X向け**：280文字以内に収める
- **Instagram向け**：改行多めで読みやすく、ハッシュタグを多めに
- **ブログ向け**：前文と後書きを追加した長めのバージョン

### ステップ4：投稿する（または投稿用テキストを保存する）

API連携が設定されている場合：
- 設定されたSNSアカウントに自動投稿

API連携がない場合：
- 投稿用テキストをファイルに保存
- ユーザーがコピー＆ペーストで投稿できるようにする

投稿履歴をログファイルに記録する（日付、テーマ、投稿先）。

### ステップ5：結果を報告する

```
今日の詩ができました：

「（タイトル）」

（詩の本文）

投稿用テキストを保存しました。SNSにコピペしてお使いください。
```

## Cron自動化の設定方法

完全自動化するには、以下のようにCronトリガーを設定します：

1. Claude Codeの `schedule` スキルを使用
2. 毎朝の指定時間にこのスキルを自動実行
3. 生成された詩をTelegram Bot経由で通知、またはSNSに自動投稿

## 重要な注意点

- 同じような詩が連続しないよう、過去の投稿履歴を参照する
- 不適切な表現・政治的な内容は避ける
- ユーザーの好みの詩風がわかったら、それに寄せていく
- 投稿前にユーザーの確認を挟むモード（手動承認）も用意する
- ログファイルで過去の詩を管理し、重複を防ぐ
