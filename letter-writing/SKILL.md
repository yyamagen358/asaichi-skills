# 手紙・お礼状を書く

用件と相手を伝えるだけで、季節の挨拶付きの丁寧な手紙文を作成します。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「手紙」「お礼状」「挨拶文」「便箋」と言った場合
- 「お礼を書きたい」「手紙の書き方」と言った場合
- 「年賀状」「暑中見舞い」「寒中見舞い」など季節の挨拶を頼まれた場合
- 「お悔やみ」「お見舞い」など冠婚葬祭の文面を求められた場合

## 手順

### ステップ1：必要な情報をヒアリングする

以下を丁寧に聞き取ります。一度に全部聞かず、会話の流れで自然に確認します：

1. **誰に出す手紙ですか？**（例：友人、恩師、親戚、取引先）
2. **どんな用件ですか？**（例：お礼、お祝い、お詫び、近況報告）
3. **何かエピソードはありますか？**（具体的な出来事があれば手紙に深みが出ます）
4. **どのくらい丁寧にしますか？**（かしこまった感じ／親しみのある感じ）

### ステップ2：季節の挨拶を選ぶ

現在の月に合わせた時候の挨拶を自動で選びます：

- 1月：厳寒の候 / 寒さ厳しき折
- 2月：余寒の候 / 梅のつぼみもふくらみ
- 3月：早春の候 / 桜の便りが届く頃
- 4月：陽春の候 / 花の盛りの季節
- 5月：新緑の候 / 風薫る季節
- 6月：梅雨の候 / 紫陽花が美しい季節
- 7月：盛夏の候 / 暑さ厳しき折
- 8月：残暑の候 / 立秋とは名ばかりの暑さ
- 9月：初秋の候 / 朝夕涼しくなり
- 10月：秋涼の候 / 金木犀の香る季節
- 11月：晩秋の候 / 紅葉の美しい季節
- 12月：師走の候 / 年の瀬も押し迫り

### ステップ3：手紙を生成する

以下の構成で手紙文を作成します：

```
【頭語】拝啓（親しい人なら省略可）

【時候の挨拶】○○の候、ますますご清祥のこととお喜び申し上げます。

【本文】用件・エピソード・気持ちを丁寧に

【結びの挨拶】ご自愛ください等

【結語】敬具（親しい人なら「かしこ」や省略可）

【日付・差出人】
```

### ステップ4：確認と調整

生成した手紙を見せて、以下を確認します：

- 「長さはいかがですか？もう少し短く（長く）もできます」
- 「言い回しで気になるところはありますか？」
- 「このまま便箋に書き写せる形でよろしいですか？」

## 重要な注意点

- 高齢者にとって手紙は大切なコミュニケーション手段。心を込めた文面を作る
- 敬語のレベルは相手との関係性に合わせる（堅すぎても親しすぎてもダメ）
- お悔やみの手紙では「重ね重ね」「たびたび」など忌み言葉を避ける
- 縦書き・横書きの指定があれば、それに合わせた改行を意識する
- ユーザーの言葉遣いや人柄が反映されるよう、聞き取った表現を活かす
