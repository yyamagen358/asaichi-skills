# Excelで家計簿

費目と金額を伝えるだけで、見やすいグラフ付きの家計簿Excelファイルを自動で作ります。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「家計簿」「出費」「Excel」「お金の管理」と言った場合
- 「今月いくら使ったか知りたい」と言われた場合
- 「支出をまとめたい」「家計を見える化したい」と言われた場合
- 「エクセルで表を作って」と頼まれた場合

## 手順

### ステップ1：費目と金額をヒアリングする

やさしく聞き取ります。かしこまりすぎず、会話の流れで：

```
今月の出費を教えてください。
たとえば「食費 3万円、病院 5千円」のように、
ざっくりで大丈夫ですよ。
```

よくある費目の例を示して、思い出しやすくします：

- 食費（スーパー、外食）
- 日用品（ドラッグストア等）
- 医療費（病院、薬局）
- 交通費（バス、タクシー）
- 光熱費（電気、ガス、水道）
- 通信費（電話、インターネット）
- 趣味・娯楽
- 交際費（お祝い、お香典等）
- その他

### ステップ2：Excelファイルを生成する

Pythonスクリプト（openpyxlライブラリ）を使ってExcelファイルを生成します。

ファイルに含める内容：

1. **一覧表シート**
   - 費目、金額、割合（%）
   - 合計行
   - 見やすいフォントサイズ（14pt以上）
   - セルの背景色で見やすく

2. **グラフシート**
   - 円グラフ（費目ごとの割合）
   - 色分けしてわかりやすく
   - 文字を大きめに

3. **月ごとの推移**（過去データがある場合）
   - 棒グラフで月ごとの比較

```python
# Excelファイル生成のイメージ
import openpyxl
from openpyxl.chart import PieChart, Reference

wb = openpyxl.Workbook()
ws = wb.active
ws.title = "家計簿"

# ヘッダー
ws['A1'] = '費目'
ws['B1'] = '金額'
ws['C1'] = '割合'

# データ入力...
# グラフ作成...

wb.save('家計簿_2026年3月.xlsx')
```

### ステップ3：ファイルを保存して案内する

生成したファイルをユーザーのわかりやすい場所に保存します：

```
家計簿ができました！デスクトップに保存しました。
「家計簿_2026年3月.xlsx」というファイルです。

今月の合計は○○円でした。
食費が全体の△△%で一番大きいですね。
```

### ステップ4：簡単なアドバイスを添える

押しつけがましくない範囲で：

```
ちなみに先月と比べると、○○費が少し増えていますね。
来月も記録すると、お金の流れがもっと見えやすくなりますよ。
```

### ステップ5：次回の使い方を案内する

```
来月も「家計簿つけて」と声をかけてくだされば、同じように作りますよ。
続けると月ごとの比較グラフも作れます。
```

## 重要な注意点

- 金額は正確に扱う。四捨五入や切り捨てをする場合は明示する
- フォントサイズは大きめに設定する（高齢者が見やすいように14pt以上）
- 色使いは見やすく。赤と緑の組み合わせは色覚に配慮して避ける
- お金の話はデリケート。「使いすぎ」などの否定的な表現は避ける
- openpyxlが使えない環境の場合は、CSVファイルで代替する
- ファイルの保存場所は必ずユーザーに確認する
