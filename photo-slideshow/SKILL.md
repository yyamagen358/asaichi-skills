# スマホ写真をスライドショーに

写真を受け取り、PowerPoint形式のスライドショーを自動で作成します。家族旅行、イベント、思い出の写真をきれいにまとめます。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「スライド」「スライドショー」と言った場合
- 「PowerPoint」「パワポ」「写真をまとめ」と言った場合
- 「写真をきれいに並べたい」「アルバムを作りたい」と言った場合
- 複数の画像ファイルが提供された場合で、まとめたい意図がある場合

## 手順

### ステップ1：写真を受け取る

ユーザーに写真ファイルを提供してもらいます。ファイルが無い場合は、やさしく以下のように案内します：

```
スライドショーにしたい写真を送ってください。
フォルダのパスを教えていただいても大丈夫です。
例：「デスクトップの旅行フォルダの写真全部」
```

以下も確認します：
- スライドショーのタイトル（例：「2026年 家族旅行」）
- テーマや雰囲気（シンプル、華やか、モノクロなど）
- 写真ごとのキャプション（あれば）

### ステップ2：写真を確認・整理する

提供された写真ファイルを確認します：
- 対応形式：jpg、jpeg、png、bmp、gif
- ファイル名やEXIF情報から日付順に並べ替え
- 画像の向き（縦・横）を確認してレイアウトを決定

### ステップ3：PowerPointスライドショーを生成する

`python-pptx` ライブラリを使ってPowerPointファイルを生成します。

```bash
pip install python-pptx Pillow
```

Pythonスクリプトで以下を含むPowerPointを生成：

- **表紙スライド**：タイトルと日付
- **写真スライド**：1枚ずつまたは2〜4枚のグリッドレイアウト
  - 横写真：画面いっぱいに配置
  - 縦写真：中央に配置、背景色を設定
- **キャプション**：写真の下にテキストを配置（あれば）
- **エンディングスライド**：「ありがとうございました」など
- スライドのトランジション（切り替え効果）を設定

### ステップ4：完成を報告し、追加対応を提案する

ファイルの保存場所を伝えた後、以下を提案します：

- 「BGM付きの動画版も作れますよ」
- 「写真の順番を変えましょうか？」
- 「キャプションを追加・変更しますか？」

## 重要な注意点

- 写真の枚数が多い場合は、途中経過を伝える（「10枚中5枚処理しました…」）
- 画像の解像度が大きすぎる場合は適切にリサイズする（ファイルサイズ節約）
- `python-pptx` がインストールされていない場合は自動でインストールする
- プライベートな写真を扱うため、内容に関する余計なコメントはしない
- ファイル名はわかりやすい日本語にする（例：「家族旅行2026.pptx」）
