# 写真のアルバム説明文

写真を見て、アルバムに添えるあたたかい一言コメントを作成します。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「アルバム」「写真にコメント」「一言」と言った場合
- 画像ファイル（jpg、png等）が提供された場合
- 「この写真に何か書きたい」「思い出を残したい」と言った場合
- 「キャプション」「説明文」「タイトル」を写真につけたいと言った場合

## 手順

### ステップ1：写真を受け取る

ユーザーから写真を受け取ります。ファイルが無い場合は：

```
写真をドラッグ＆ドロップしてください。
複数枚まとめてでも大丈夫ですよ。
```

### ステップ2：写真を観察する

Readツールで画像を読み取り、以下を観察します：

- **場所**：どこで撮られた写真か（室内、屋外、観光地、自宅など）
- **人物**：誰が写っているか（人数、年齢層、表情）
- **季節**：いつ頃の写真か（服装、植物、風景から推測）
- **雰囲気**：楽しそう、穏やか、にぎやか、厳かなど
- **特徴的なもの**：食べ物、花、動物、建物など

### ステップ3：コメントを生成する

以下のようなバリエーションで、あたたかみのあるコメントを3つ提案します：

1. **情景描写型**：「桜の下で笑い合った春の午後」
2. **気持ち型**：「みんなの笑顔が一番のごちそう」
3. **記録型**：「2024年 家族旅行 箱根にて」

コメントの特徴：
- 短く、便箋やアルバムに書きやすい長さ（1〜2行）
- あたたかく、懐かしさを感じる言葉遣い
- 押しつけがましくない、さりげない表現

### ステップ4：ユーザーの気持ちを反映する

ユーザーが写真についてエピソードを話してくれたら、その言葉を活かしたコメントに調整します：

```
素敵なエピソードですね。それを活かして、こんなコメントはいかがですか？
```

### ステップ5：複数枚の場合はまとめて対応

複数の写真が提供された場合は、一枚ずつコメントを作成します。アルバム全体のタイトルも提案します：

```
アルバム全体のタイトルも考えてみました：
「○○家の宝物 〜笑顔あふれる日々〜」
```

## 重要な注意点

- 写真に写っている人の名前は推測しない。ユーザーに確認する
- ネガティブな表現は避ける（「疲れた顔」「寂しそう」など）
- 故人が写っている可能性もある。慎重に、敬意を持って対応する
- 手書きで写す場合を考え、コメントは短めに（30文字以内が理想）
- 季節感や情緒を大切にする。日本の四季の美しさを活かす
