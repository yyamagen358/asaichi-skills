# 販売用LP作り

商品やサービスの情報をヒアリングし、売れるランディングページ（LP）をHTML単体ファイルで自動生成します。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「LP」「ランディングページ」と言った場合
- 「販売ページ」「商品ページ」「申し込みページ」と言った場合
- 「ページを作って」「売るためのページ」と言った場合
- 副業やネット販売で商品を売りたいという意図がある場合

## 手順

### ステップ1：商品・サービスの情報をヒアリングする

ユーザーに以下を確認します：

```
売れるLPを作りましょう！以下を教えてください：

1. 何を売りますか？（商品名・サービス名）
2. 誰に売りますか？（ターゲット）
3. いくらですか？（価格）
4. お客さんの悩みは何ですか？
5. この商品でどう解決しますか？
6. お客様の声や実績はありますか？（あれば）

全部じゃなくても大丈夫です。わかる範囲で教えてください。
```

### ステップ2：LPの構成を設計する

ヒアリング内容をもとに、以下の構成でLPを設計します：

1. **ファーストビュー**：キャッチコピー + メインビジュアル + CTAボタン
2. **悩み共感セクション**：ターゲットの悩みを列挙
3. **解決策の提示**：商品・サービスの紹介
4. **特徴・メリット**：3〜5個のベネフィット（アイコン付き）
5. **お客様の声**：実績やレビュー（あれば）
6. **料金・プラン**：価格表
7. **よくある質問**：FAQ（3〜5個）
8. **最終CTA**：申し込みボタン + 限定感の演出
9. **フッター**：連絡先・特定商取引法表示

### ステップ3：HTML単体ファイルを生成する

以下の仕様でHTMLファイルを作成します：

- **HTML単体ファイル**：CSS・JavaScriptはすべてインライン
- **レスポンシブ対応**：スマホ・タブレット・PCすべてで見やすい
- **デザイン**：
  - モダンでクリーンなデザイン
  - CTAボタンは目立つ色（オレンジや緑）
  - セクション間に適切な余白
  - スクロールアニメーション（軽量なCSS animationのみ）
- **SEO基本対応**：meta description、OGP設定
- **高速表示**：外部リソースに依存しない

ファイルをWriteツールで出力します。

### ステップ4：プレビュー確認と修正

ユーザーにファイルの場所を伝え、ブラウザで確認してもらいます：

```
LPが完成しました！ブラウザで開いて確認してみてください。

修正したい箇所があれば教えてくださいね：
- 文言の変更
- 色やレイアウトの調整
- セクションの追加・削除
```

### ステップ5：追加対応を提案する

- 「問い合わせフォームを追加しましょうか？」
- 「Googleアナリティクスのコードを埋め込みますか？」
- 「サーバーへのアップロード方法もお伝えしましょうか？」

## 重要な注意点

- 誇大広告にならないよう注意する（薬機法・景品表示法に抵触しない表現を心がける）
- ユーザーの商品を否定せず、最大限魅力的に見せるLP構成にする
- HTMLファイルは1ファイルで完結させる（画像はプレースホルダーまたはSVGで対応）
- CTAボタンのリンク先はユーザーに確認してから設定する
- スマートフォンでの表示を最優先で確認する（閲覧の大半がスマホ）
