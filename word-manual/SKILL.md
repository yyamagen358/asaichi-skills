# Wordで手順書作り

話した内容や簡単な説明から、番号付きの手順書をWord形式（.docx）で自動生成します。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「手順書」「マニュアル」と言った場合
- 「Wordで」「引継ぎ」「操作手順」と言った場合
- 「やり方をまとめたい」「手順を書き出して」と言った場合
- 「.docxで出して」「Word形式で」と言った場合

## 手順

### ステップ1：手順の内容を聞き取る

ユーザーにどんな手順書を作りたいか確認します。ファイルが無い場合は、やさしく以下のように案内します：

```
どんな手順書を作りたいですか？
例えば「パソコンの起動からメールを送るまで」「経費精算のやり方」など、
ざっくりで大丈夫です。箇条書きでもOKですよ。
```

以下の情報を聞き取ります：
- 手順書のタイトル（何の手順か）
- 対象者（誰向けか）
- 手順の概要（やることの流れ）
- 注意点やコツ（あれば）

### ステップ2：手順を番号付きで構造化する

聞き取った内容をもとに、以下の構造で手順書を整理します：

1. **タイトル**：手順書の名前
2. **目的**：この手順書で何ができるようになるか
3. **対象者**：誰向けの手順か
4. **準備するもの**：必要なツールや前提条件
5. **手順**：番号付きのステップ（各ステップに説明と注意点を含む）
6. **よくある質問**：つまずきやすいポイント

### ステップ3：Word形式（.docx）で出力する

`python-docx` ライブラリを使ってWord文書を生成します。Pythonスクリプトを作成・実行して.docxファイルを出力します。

```bash
pip install python-docx
```

Pythonスクリプトで以下を含むWordファイルを生成：
- 表紙（タイトル、作成日、作成者）
- 目次
- 番号付きの手順（見出しスタイル適用）
- 注意書きは太字やハイライトで強調
- フッターにページ番号

出力先はユーザーのデスクトップまたはカレントディレクトリとします。

### ステップ4：完成を報告し、追加対応を提案する

ファイルの保存場所を伝えた後、以下を提案します：

- 「PDF版も作りましょうか？」
- 「図や画像を追加しましょうか？」
- 「別の手順書も作りますか？」

## 重要な注意点

- ユーザーが口頭で説明する場合も、わかりやすい手順に整理する
- 専門用語は避け、初心者でもわかる表現にする
- 手順の抜け漏れがないか確認してからファイル生成する
- `python-docx` がインストールされていない場合は自動でインストールする
- ファイル名は日本語でわかりやすい名前にする（例：「経費精算の手順書.docx」）
