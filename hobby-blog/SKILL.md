# 趣味のブログ記事

旅行の思い出、趣味の話、日記などを、note.comに投稿できる形式のブログ記事として作成します。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「ブログ」「日記」「旅行記」「noteに投稿」と言った場合
- 「記事を書きたい」「文章にまとめたい」と言われた場合
- 「旅行の思い出を残したい」「趣味について書きたい」と言われた場合
- 「noteに載せたい」「投稿用の文章を作って」と頼まれた場合

## 手順

### ステップ1：テーマと内容をヒアリングする

会話の中で自然に聞き取ります：

```
どんな記事を書きましょうか？
たとえば…
・旅行の思い出
・趣味（園芸、料理、散歩、読書など）
・最近あった出来事
・昔の思い出話

何でも記事にできますよ。ざっくり教えてください。
```

以下の情報を集めます（全部揃わなくてOK）：

1. **テーマ**：何について書くか
2. **エピソード**：具体的な出来事、印象に残ったこと
3. **気持ち**：嬉しかった、驚いた、懐かしかった等
4. **写真**：あれば記事に添える（なくても可）

### ステップ2：記事の構成を作る

note.comに適した構成で下書きを作ります：

```markdown
# タイトル（興味を引く、温かみのあるもの）

導入文（2〜3行で読者の心をつかむ）

## 見出し1
本文（エピソードを交えて）

## 見出し2
本文（五感を使った描写を入れる）

## 見出し3
本文（気づきや感想）

---
おわりに（まとめと読者への語りかけ）
```

### ステップ3：記事を生成する

以下のポイントを押さえて記事を書きます：

- **語り口調**：堅すぎず、日記のような親しみやすさ
- **五感の描写**：「風が心地よかった」「出汁の香りが漂って」など
- **具体的なエピソード**：ユーザーが語ってくれた内容を活かす
- **適度な長さ**：1000〜2000文字程度（noteの読者が読みやすい長さ）
- **段落は短めに**：スマホで読む人にも配慮

### ステップ4：タイトルの候補を提案する

タイトルは記事の顔。3つほど候補を出します：

```
タイトルの候補を考えてみました：

1. 「70歳、はじめての一人旅で見つけたもの」
2. 「箱根の湯けむりに癒された三日間」
3. 「温泉と蕎麦と、ちょっとした冒険と」

どれがお好みですか？アレンジもできますよ。
```

### ステップ5：確認と調整

```
記事ができました。読んでみてください。

・もう少し長くしたい／短くしたい
・この部分をもっと詳しく
・言い回しを変えたい

何でも調整しますので、遠慮なく言ってくださいね。
```

### ステップ6：投稿方法を案内する

note.comへの投稿手順を簡単に案内します：

```
noteへの投稿手順：
1. note.com にログイン
2. 右上の「投稿」ボタンを押す
3. 「テキスト」を選ぶ
4. この記事をコピー＆ペーストする
5. 写真があれば追加する
6. 「公開」ボタンを押す

コピーしやすいように、テキストファイルとしても保存しましょうか？
```

## 重要な注意点

- ユーザーの言葉をなるべく活かす。「代わりに書く」のではなく「一緒に書く」姿勢
- 個人情報（住所、本名、病名など）が含まれていないか確認し、注意を促す
- 写真に位置情報が含まれている可能性がある旨を伝える
- 著作権に注意。他人の文章や歌詞をそのまま使わない
- ユーザーの年齢や経験を尊重する。上から目線にならない
- noteのマークダウン記法はシンプルなものだけ使う（複雑な記法は避ける）
