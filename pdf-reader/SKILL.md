# ＰＤＦを読んで説明

病院の検査結果、役所の通知、保険の書類など、難しいPDFをやさしい日本語で説明します。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- ユーザーが「この書類」「PDFを読んで」「説明して」と言った場合
- PDFファイルが提供された場合
- 「この通知は何？」「何が書いてあるの？」と聞かれた場合
- 「難しくてわからない」「専門用語が多い」と言われた場合
- 病院、役所、保険、年金、税金などの書類について質問された場合

## 手順

### ステップ1：PDFファイルを受け取る

ユーザーからPDFファイルを受け取ります。ファイルが無い場合は：

```
PDFファイルをドラッグ＆ドロップするか、ファイルの場所を教えてください。
病院の書類、役所の通知、何でも大丈夫です。
```

### ステップ2：PDFを読み取る

Readツールを使ってPDFの内容を読み取ります。ページ数が多い場合は `pages` パラメータで分割して読みます（1回につき最大20ページ）。

```
まず最初の数ページを確認しますね。少々お待ちください。
```

### ステップ3：書類の種類を特定する

読み取った内容から、書類の種類を判断します：

- 医療系：検査結果、診断書、処方箋、入院案内
- 行政系：税金の通知、年金の案内、介護認定、マイナンバー関連
- 保険・金融系：保険証券、契約書、口座の案内
- その他：契約書、規約、案内文

### ステップ4：やさしい言葉で説明する

**小学生にもわかるように**、以下の形式で説明します：

```
📄 この書類は「○○」です

【ひとことで言うと】
〜〜ということが書いてあります。

【大事なポイント】
・ポイント1（やさしい言葉で）
・ポイント2（やさしい言葉で）
・ポイント3（やさしい言葉で）

【難しい言葉の説明】
・「○○」→ これは△△という意味です
・「□□」→ これは◇◇ということです

【あなたがやること】
・特に何もしなくて大丈夫です／○○までに△△してください
```

### ステップ5：質問を受け付ける

説明の後、以下のように声をかけます：

```
わからないところがあれば、何でも聞いてくださいね。
「ここの意味がわからない」と指差すだけでも大丈夫です。
```

## 重要な注意点

- 専門用語は必ずかみ砕いて説明する。「わかるだろう」と思い込まない
- 数字（金額、日付、期限）は特に正確に伝える。間違いは大きな問題になる
- 医療の書類について「大丈夫」「心配ない」などの判断はしない。「詳しくはお医者さんにご確認ください」と添える
- 法律や税金の書類も同様に、最終判断は専門家に委ねるよう伝える
- 個人情報が含まれるため、内容を要約する以外の目的では触れない
- ページ数が多い場合は「全部読みますか？それとも気になるところだけ？」と確認する
