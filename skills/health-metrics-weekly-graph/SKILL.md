# 健康管理 週間グラフ作成スキル

毎日の血圧と体重を簡単に記録できます。自動的にデータが蓄積され、1週間ごとにグラフを作ってくれるので、健康管理が一目でわかります。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- 毎日、朝の同じ時間に血圧と体重を測定したあと
- 1週間分のデータをまとめてグラフで見たいとき
- 血圧や体重の変化傾向を確認したいとき
- 医師の診察に向けて、最近のデータをまとめたいとき

## 手順

### ステップ1：毎日の記録を始める

朝、同じ時間に測定した血圧と体重を教えてください。以下のように話しかけるだけです：

**話しかけ例：**
```
「今日の測定値を記録してください。血圧は140の90で、体重は65キロです」

または

「血圧：上が135、下が85。体重は64.5キロ」
```

スキルが自動的にデータを日付つきで保存します。

### ステップ2：データの確認

記録されたか確認したいときは、以下のように聞いてください：

**話しかけ例：**
```
「今までの記録を見せてください」
「この1週間のデータを表示してください」
```

スキルが最新10件までのデータを一覧で見せます。

### ステップ3：自動で週間グラフを作成

スキルは毎週日曜日の朝に自動的にグラフを作ります。または、以下のように頼むこともできます：

**話しかけ例：**
```
「今週のグラフを作ってください」
「先週1週間分のグラフを見せてください」
```

### ステップ4：グラフで変化を確認

グラフには以下の情報が表示されます：

**血圧グラフの例：**
```
血圧の推移（上の値）
月：135  火：137  水：133  木：132  金：130  土：131  日：128
（上向き矢印で改善を示す場合もあります）
```

**体重グラフの例：**
```
体重の推移
月：65.2kg → 火：65.0kg → 水：64.8kg → 木：64.6kg 
金：64.5kg → 土：64.7kg → 日：64.4kg
（下向き矢印や棒グラフで変化が見やすいです）
```

### ステップ5：データの活用と相談

グラフから気になることがあれば、聞いてみてください：

**話しかけ例：**
```
「血圧が高い日と低い日で何か違いがありますか？」
「この1ヶ月の体重の傾向を教えてください」
「グラフを医師に見せたいのですが、印刷できますか？」
```

スキルが傾向の分析やアドバイスを提供します。

## 重要な注意点

- **毎日同じ時間に測定してください** 朝の起床後30分以内が理想的です（血圧は時間帯で変わります）
- **安静状態で測定してください** 測定の5分前は座ってリラックスしてから測定してください
- **医学的アドバイスではありません** グラフの結果に不安があれば、必ず医師に相談してください
- **データは安全に保管されます** 記録されたデータはプライベートに保管されます
- **欠落がある場合はスキップされます** 測定できない日があっても大丈夫です。スキップして続けてください
- **3週間以上のデータで精度が上がります** はじめの1～2週間は傾向がまだはっきりしないので、続けることが大事です
- **グラフは毎週更新されます** 古いグラフは保存され、最新のものはいつでも見られます
