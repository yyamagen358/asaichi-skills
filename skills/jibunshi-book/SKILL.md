# 自分史・昔話を本にする

あなたの人生の思い出を、一冊の本にまとめるお手伝いをします。
むずかしい操作は必要ありません。質問に答えて話すだけで、AIが文章を整えて、立派な自分史を作ります。
お孫さんやご家族へのプレゼントにもぴったりです。

## いつこのスキルを使うか

- 自分の人生をふりかえって、記録に残しておきたいと思ったとき
- お孫さんやお子さんに「おじいちゃん・おばあちゃんの話」を伝えたいとき
- 家族の歴史や昔の暮らしを、次の世代に残したいとき
- 喜寿・傘寿・米寿などのお祝いに、記念の本を作りたいとき
- 亡くなった方の思い出を、家族みんなでまとめたいとき
- 昔話を誰かに聞いてほしい、語りたい気持ちがあるとき
- 自治体や地域の「語り部」活動の記録を残したいとき

## 手順

### ステップ1: あなたのことを教えてください

まず、かんたんな自己紹介をお願いします。
すべて答えなくても大丈夫です。話せるところだけで構いません。

AIにこのように伝えてください。

```
わたしの名前は山田太郎です。
昭和10年生まれ、今年91歳です。
生まれは新潟県長岡市です。
今は東京都の練馬区に住んでいます。
```

AIが以下のような「プロフィールカード」を作ります。

```
┌────────────────────────────┐
│  自分史プロフィール         │
├────────────────────────────┤
│  お名前：山田 太郎さま      │
│  生年月日：昭和10年3月15日  │
│  出身地：新潟県長岡市       │
│  現住所：東京都練馬区       │
│  ご家族：妻、子2人、孫4人   │
└────────────────────────────┘
```

内容がちがっていたら、遠慮なく「ここを直して」と言ってください。

### ステップ2: 本の構成（もくじ）を決める

人生を時代ごとに分けて、本の「もくじ」を作ります。
下の見本をもとに、AIがあなたに合った構成を提案します。

```
『山田太郎 わたしの歩いた道』 もくじ（案）

  はじめに ── この本を手にとってくれたあなたへ

  第1章　幼いころの思い出（0歳〜12歳）
    ・生まれた家と家族のこと
    ・近所の遊び、学校のこと

  第2章　青春のころ（13歳〜20歳）
    ・戦争の記憶
    ・終戦のあの日

  第3章　社会に出て（21歳〜35歳）
    ・はじめての仕事
    ・結婚と新しい生活

  第4章　働きざかり（36歳〜55歳）
    ・子育てのこと
    ・仕事でうれしかったこと、大変だったこと

  第5章　人生の実り（56歳〜現在）
    ・定年後のたのしみ
    ・孫たちのこと

  おわりに ── これからの夢、伝えたいこと
```

もくじは自由に変えられます。「趣味の章を増やしたい」「戦争の話は別の章にしたい」など、ご希望をお伝えください。

### ステップ3: 思い出を話す（インタビュー形式）

ここが一番たのしいところです。
AIが質問をしますので、思い出すままにお話しください。長くても短くても構いません。

AIはこのような質問をします。

```
【第1章 幼いころの思い出について】

 Q1. 生まれた家は、どんなところでしたか？
     まわりの景色や、家のようすを覚えていますか？

 Q2. 子どものころ、どんな遊びをしましたか？
     仲のよかったお友だちはいましたか？

 Q3. お父さん、お母さんは、どんな方でしたか？
     よく言われた言葉や、思い出の場面はありますか？

 Q4. 学校で楽しかったこと、印象に残っていることは？

 Q5. 子どものころに食べた、忘れられない味はありますか？
```

答えの例はこのような感じです。

```
Q1への答え:
「うちは農家でね、まわりは田んぼばっかりだったよ。
 春になると、家の裏の小川でめだかを捕まえたもんだ。
 家は茅葺き屋根の古い家でね、冬はすきま風が寒くてねえ。
 囲炉裏のそばにみんなで集まって寝たのを覚えてるよ。」
```

うまく話せなくても大丈夫です。「よく覚えてないけど寒かった」だけでも、AIが文章にまとめます。

### ステップ4: AIが文章にまとめる

お話しいただいた内容を、AIが読みやすい文章に整えます。
あなたの言葉づかいや雰囲気を大切にしながら、本の文章にします。

```
第1章　幼いころの思い出

　わたしが生まれたのは、新潟県長岡市の小さな農村だった。
家のまわりは一面の田んぼで、春になると関の小川には
めだかが銀色にきらきらと泳いでいた。

　家は茅葺き屋根の古い造りで、冬になるとすきま風が
容赦なく吹き込んだ。家族みんなで囲炉裏のそばに
身を寄せ合い、わらの布団にくるまって眠ったものである。

　あの囲炉裏の温かさと、味噌汁のにおいは、
八十年以上たった今でも、はっきりと思い出すことができる。
```

気に入らないところがあれば、「もっとやさしい言い方にして」「方言を残して」など、何でもお伝えください。何度でも書き直します。

### ステップ5: すべての章をくりかえす

ステップ3とステップ4を、各章ごとにくりかえします。
一度にぜんぶ話さなくても大丈夫です。

```
進みぐあいの例:

  第1章　幼いころの思い出    ✅ 完成
  第2章　青春のころ          ✅ 完成
  第3章　社会に出て          📝 いま取り組み中
  第4章　働きざかり          ⬜ まだこれから
  第5章　人生の実り          ⬜ まだこれから
  はじめに・おわりに         ⬜ 最後にまとめます
```

「今日は疲れたから続きはまた今度」でまったく問題ありません。何日かけても、何週間かけても大丈夫です。

### ステップ6: 「はじめに」と「おわりに」を書く

すべての章ができたら、最初と最後の言葉を書きます。
AIが下書きを作りますので、お好きなように直してください。

```
はじめに ── この本を手にとってくれたあなたへ

　この本は、わたし山田太郎の九十一年の歩みを
つづったものです。

　たいした人間ではありませんが、この時代に生まれ、
戦争を乗り越え、家族に恵まれ、ここまで来ることが
できました。

　この本が、いつか孫やひ孫が「おじいちゃんは
こんな人だったんだ」と知るきっかけになれば、
これほどうれしいことはありません。

　令和八年 春
　　山田 太郎
```

### ステップ7: 本の形にして完成

すべてまとまったら、AIが本の形式にまとめます。
ご希望に合わせて、以下の形でお渡しできます。

```
できあがりの形式:

  ① Markdown形式（.md）
     → パソコンやスマートフォンで読めます

  ② Word形式の下書き（構成つき）
     → 印刷所に持ち込んで製本できます

  ③ 章ごとの分割ファイル
     → 少しずつ家族にLINEなどで送れます
```

表紙の例はこのようになります。

```
╔══════════════════════════════════╗
║                                  ║
║    わたしの歩いた道              ║
║                                  ║
║    ── 九十一年のあゆみ ──       ║
║                                  ║
║                                  ║
║           山田 太郎              ║
║                                  ║
║         令和八年 春              ║
║                                  ║
╚══════════════════════════════════╝
```

## 重要な注意点

- **途中でやめても大丈夫です。** 疲れたら「今日はここまで」と言ってください。続きはいつでも再開できます
- **正確でなくても構いません。** 年号や日付があいまいでも気にしないでください。覚えているままにお話しください。AIが「昭和20年ごろ」のように、やわらかく表現します
- **話したくないことは話さなくて大丈夫です。** つらい思い出や、ふれたくないことは遠慮なく「飛ばして」とお伝えください
- **方言や話し言葉を大切にします。** 「標準語に直して」「方言のまま残して」など、お好みをお伝えください。あなたらしさを一番大事にします
- **何度でも書き直せます。** 「やっぱりこう言いたい」「思い出したことがある」など、いつでも修正できます。完成を急ぐ必要はありません
- **ご家族といっしょに使うこともできます。** お子さんやお孫さんが横について、いっしょに聞きながら進めると、より豊かな本になります
- **プライバシーを守ります。** 実名を仮名にしたい、地名をぼかしたいなど、ご相談ください
- **写真や絵の挿入場所も指定できます。** 「ここに家族写真を入れたい」と言っていただければ、挿入位置を本の中に記しておきます
