# 短歌添削スキル

あなたが書いた短歌を、文法・表現・音韻・季語などの観点から丁寧に添削します。初めての短歌から、より洗練された表現を目指す上級者まで、誰でも使えます。

## いつこのスキルを使うか

以下のような場合にこのスキルを使ってください：

- 自分が書いた短歌を誰かに見てもらいたいとき
- 短歌の表現がおかしくないか確認したいとき
- より良い言葉選びのアドバイスが欲しいとき
- 音のリズムが正しいか確認したいとき
- 短歌の決まりごと（5-7-5-7-7の31音など）が守れているか見てもらいたいとき

## 手順

### ステップ1：短歌を読み上げる

あなたが書いた短歌を、そのまま読み上げてください。複数の短歌がある場合は、全てお聞きします。

**例：「春の月 柔らかく照る 古池に 鯉のはね打つ 音も優し」**

### ステップ2：形式と音数をチェック

短歌の基本である「5-7-5-7-7」の31音に正しくおさまっているかを確認します。音数が合っていない場合は、どこをどのように直すかをお伝えします。

**例の確認：**
```
春の月（5音）
柔らかく照る（7音）
古池に（5音）
鯉のはね打つ（7音）
音も優し（5音）
```
✓ 正しい形です

### ステップ3：表現と意味をチェック

短歌に使われている言葉や表現が、本当に伝えたい気持ちや情景をしっかり表現できているかを見ます。より自然な表現や、より心に響く言葉があれば提案します。

**例の場合：**
- 「柔らかく照る」の表現は美しく、春の月の優しさがよく伝わります
- 「音も優し」は情景を余韻をもって終わらせていて良いです

### ステップ4：季語と季節感をチェック

短歌に季語が使われているか、そして季語が季節にぴったり合っているかを確認します。季語がない場合は、入れた方がいいかもお伝えします。

**例の場合：**
- 「春の月」は春の季語として正しい
- 古池の鯉という情景も春のイメージに合っている

### ステップ5：音の響きをチェック

短歌を声に出して読んだときの、音韻のバランスや流れ感をチェックします。読みにくい部分や、より滑らかに読める言葉の組み合わせがあれば提案します。

**例の場合：**
```
春の月 柔らかく照る 古池に 鯉のはね打つ 音も優し
↑ 「ら行」が多く、柔らかな響きがある
```

### ステップ6：改善案と講評をお伝えする

チェックした内容をまとめて、改善案や励ましのお言葉をお伝えします。もし短歌の背景にある想いや情景があれば、教えていただくと、より的確なアドバイスができます。

**改善案の形式：**
```
【現在の短歌】
春の月 柔らかく照る 古池に 鯉のはね打つ 音も優し

【講評】
美しい情景が浮かぶ良い短歌です。特に「音も優し」で
静寂と音が対比されていて、夜明けの静けさが表現されています。

【改善案の例】
春の月 柔らかく照る 古池の 鯉のはね打つ 音澄みたり
→ より古語の美しさが引き出されます
```

### ステップ7：質問や追加添削に対応

添削後に、「この表現についてもっと知りたい」「別の言葉は？」などの質問にお答えします。何度でも改良案を提案できます。

## 重要な注意点

- **短歌の決まりを優先：** 5-7-5-7-7の31音が最も大切です。言葉の選び方よりもまず形式を整えることをお勧めします
- **個性を尊重：** 添削は「より良くする案」であり、あなたの表現を否定するものではありません。提案を参考にしつつ、あなたの想いを大切にしてください
- **季語について：** 短歌には必ず季語が必要というわけではありませんが、あると季節感が出ます
- **古語と現代語：** 古い言葉を使うと格調高くなりますが、伝わりやすさも大切です。用途に応じて提案します
- **音読が大切：** 完成後は、必ず声に出して読んでみてください。目で読むのと耳で聞くのでは印象が変わることがあります
- **複数の視点：** 短歌は作品によって、複数の解釈ができることがあります。もし「別の読み方がある」と感じたら、それも素晴らしいことです
